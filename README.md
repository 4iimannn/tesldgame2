# TESL D: The Last Period — Full Browser Game

A GitHub Pages-ready social puzzle/adventure game for TESL D at IPGKBA.

## Features
- 27 selectable TESL D characters
- Character personalities and routes
- Day/time progression
- Explorable, visually distinct locations
- TESL D Class, Gymnasium, Volleyball Court, Canteen, Averroes Hall and Vista Angkasa
- Dialogue system
- Character quests
- Quest chains and class-specific interactions
- Inventory and photo collectible system
- Day restart and local save
- Multiple day endings
- Responsive UI
- No build step and no external game engine

## Run
Open `index.html` in a modern browser.

## GitHub Pages
Upload the project files to a repository, then:
Settings -> Pages -> Deploy from branch -> main -> / (root)

## Important
The class photo is included as `assets/class-photo.png`.
The environments are drawn directly in JavaScript canvas so the game remains self-contained and easy to host.
